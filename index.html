Политика конфиденциальности

Приложение «Кабинет репетитора»

Версия 1.0.2 · Редакция от 15 октября 2026 года

1. Область действия и контакт

Эта политика описывает обработку данных в Android-приложении «Кабинет репетитора», начиная с версии 1.0.2. Приложение предназначено для организации работы репетитора. Регистрация и создание аккаунта не требуются.

Разработчик и контакт по вопросам конфиденциальности: Дмитрий. Электронная почта: tutor.cabinet.support@gmail.com.

2. Данные и цели обработки

Пользователь вводит данные самостоятельно либо восстанавливает их из выбранного файла резервной копии.

Имена учеников и родителей, контактные телефоны используются для ведения карточек и подготовки общения. Изучаемый язык и обычная стоимость урока — для организации занятий.

Даты, время, продолжительность, участники, темы и статусы занятий используются для расписания, истории и напоминаний. Итоги уроков, домашние задания и заметки — для сопровождения обучения и подготовки сообщения родителю.

Суммы, даты и комментарии к оплатам, стоимость проведённых занятий, задолженность и авансы используются для ручного финансового учёта. Реквизиты банковских карт не запрашиваются; приложение не принимает и не переводит деньги.

Файлы резервных копий JSON используются для экспорта и восстановления этих записей. Локальные идентификаторы записей, настройки и часовой пояс устройства используются для связи записей, отображения интерфейса и планирования уведомлений.

Приложение ведёт собственные карточки и расписание и не читает адресную книгу или календарь телефона. Не следует вводить паспортные данные, сведения о здоровье и другую информацию, не требующуюся для перечисленных функций.

3. Локальное хранение и резервирование

Рабочая база сохраняется в области данных приложения на устройстве. В этой версии не предусмотрены сервер разработчика для рабочей базы, автоматическая облачная синхронизация, рекламные SDK и сервисы аналитики поведения пользователей. Рабочие записи не отправляются разработчику автоматически.

В версии 1.0.2 системное облачное резервирование и штатный перенос области данных приложения между Android-устройствами исключены настройками манифеста и правилами резервирования. Для переноса данных используется ручная JSON-копия. Эти настройки не удаляют системные копии, которые могли быть созданы предыдущими версиями, и не управляют сторонними средствами копирования производителя телефона.

Разработчик не имеет дистанционного доступа к локальной базе и не может удалить её по обращению в поддержку.

4. Уведомления и разрешения

Разрешение на уведомления используется для локальных напоминаний о занятиях. Разрешение на точные будильники используется для планирования времени напоминания. Событие перезагрузки устройства используется библиотекой уведомлений для восстановления запланированных напоминаний.

Уведомление содержит время урока без имени ученика. Его видимость на заблокированном экране настраивается средствами Android. Уведомления не отправляются родителям автоматически.

Разрешения можно отозвать в настройках телефона. При отказе напоминания могут не работать, но карточки учеников, расписание и финансовый учёт остаются доступны. Для резервных копий пользователь сам выбирает файл или место сохранения через системный интерфейс.

5. Передача по действиям пользователя

При экспорте пользователь создаёт файл JSON в выбранном месте. Копия содержит данные в читаемом виде и не защищается приложением отдельным паролем или шифрованием. Если пользователь выбирает облачную папку, отправляет копию другому человеку или переносит её на компьютер, дальнейшая обработка зависит от выбранного сервиса и действий пользователя.

При нажатии кнопки копирования сообщения текст помещается в системный буфер обмена. Для отправки пользователь самостоятельно вставляет его в выбранный чат и отправляет. Обработка в мессенджере регулируется условиями этого мессенджера.

Самостоятельная отправка письма в поддержку передаёт разработчику адрес отправителя, содержимое письма и приложенные файлы. Не отправляйте персональные данные учеников и родителей: для диагностики используйте обезличенные примеры.

Магазин приложений, почтовый сервис и другие самостоятельно выбранные сервисы обрабатывают данные в рамках собственных условий. Эта политика не заменяет их документы.

6. Сроки хранения и удаление

Локальные записи хранятся, пока пользователь сохраняет их в базе. Архивирование ученика и отмена урока не удаляют историю, связанные отчёты или оплаты. Исправление полей выполняется доступными средствами приложения.

Чтобы полностью удалить локальную базу, откройте настройки Android → «Приложения» → «Кабинет репетитора» → «Хранилище» и выберите очистку данных приложения. Названия пунктов зависят от телефона. Будут удалены все локальные ученики, занятия, оплаты и задания; отменить это действие без резервной копии нельзя. Очистка только кэша базу не удаляет.

Удаление приложения обычно удаляет его область данных. Экспортированные JSON-файлы, старые системные копии, отправленные сообщения и данные в других сервисах могут остаться. Их нужно удалить отдельно, включая корзины и копии на других устройствах. Восстановление старого файла JSON может вернуть ранее удалённые записи.

Данные обращения в поддержку используются для ответа и решения вопроса и удаляются после завершения обработки, когда перестают быть необходимыми для этой цели, кроме сведений, которые требуется хранить по закону. По вопросам исправления или удаления данных, непосредственно переданных разработчику, напишите на tutor.cabinet.support@gmail.com. Разработчик не может таким способом удалить данные с вашего телефона или из чужого мессенджера.

7. Данные учеников и родителей

В приложении могут храниться сведения о других людях, в том числе несовершеннолетних. Пользователь, который ведёт такие записи, должен иметь необходимые законные основания для их обработки и передачи и получать требуемые согласия, в том числе законных представителей, когда это применимо.

Следует вносить только необходимые сведения, своевременно исправлять их и удалять, когда цель хранения достигнута. Само использование приложения не заменяет оснований для обработки данных учеников.

8. Защита данных

Для рабочей базы используется изоляция приложения средствами Android. Отдельное шифрование базы и JSON-копий приложением, а также собственная блокировка входа отпечатком пальца в этой версии не реализованы.

Используйте блокировку экрана, обновления системы и защищённое место для копий. Не предоставляйте посторонним доступ к разблокированному телефону и файлам резервных копий. Перед передачей сообщения проверьте получателя и содержимое.

9. Изменения и обращения

При изменении состава данных или способов обработки политика пересматривается. Редакция, соответствующая установленной версии, доступна внутри приложения в разделе «Как пользоваться» → «Политика конфиденциальности». Публичная ссылка на политику размещается в карточке приложения RuStore. При появлении функций, для которых требуется отдельное согласие, оно должно запрашиваться в необходимых случаях.

Вопросы о конфиденциальности: tutor.cabinet.support@gmail.com.
